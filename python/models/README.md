# NTD11 model directory

Optional NTD11 detection uses `ntd11_anime_nsfw_segm_v5.pt` from the Anime NSFW Detection / ADetailer All-in-One model.

Place the model here as:

`python/models/ntd11_anime_nsfw_segm_v5.pt`

The `.pt` file is intentionally excluded from Git because model distribution is governed by the model author's license/terms and the file may be large. You can also select a model from any local path in the application's automatic mosaic settings.
